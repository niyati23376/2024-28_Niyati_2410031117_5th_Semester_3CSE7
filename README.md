📌 About the Internship

The internship focused on full-stack product development, spanning internal dashboard tools and public-facing web experiences. Work centered on two core projects: the **ETS Exception Tracking Dashboard**, an internal system-health and exception-management tool, and the **Crash Course Project**, a content and UI initiative converting study material into a responsive web format. The role combined frontend UI design, backend/data integration, and workflow automation across both projects.

 🎯 Objectives

- Design and build an internal exception-tracking dashboard with real-time system-health metrics
- Implement search, filtering, and reviewer-assignment workflows for exception management
- Integrate duplicate-identity detection data into exception records for faster resolution
- Add AI-generated summaries to key actions to improve internal team context
- Review and improve email/notification schema for clearer, more actionable alerts
- Convert structured PDF learning content into responsive, accessible HTML pages
- Ensure UI consistency and responsiveness across devices for both projects

🗂️ Project Breakdown

 ETS Project
- Designed and developed the ETS Dashboard/Overview page, including the Hero Section and key system-health metrics
- Implemented key metric cards for Total Exceptions, Open, Under Review, and Resolved cases
- Built a visual exception-type breakdown for quick system-health insights
- Designed and developed the Exceptions Management page with search and filtering by exception type and status
- Implemented inline reviewer assignment, automation retry triggers for failed processes, and an exception-resolution workflow with resolution notes
- Integrated duplicate identity data from the `duplicate_identity` table into the exceptions view, displaying match reason, identity fingerprint, and detection date
- Integrated AI-generated summaries for key actions (assign, retry, resolve) to provide clearer context for internal teams
- Reviewed the existing email schema and notification templates, suggesting improvements to data fields and message content
- Overall focus: making exception handling faster, more transparent, and easier to act on for the internal team

 Crash Course Project
- Designed and developed poster layouts for the Crash Course project
- Converted subject-wise PDF notes into structured HTML pages, making learning material accessible in a web-based format
- Processed and structured content across multiple subjects while maintaining consistent layout and styling
- Worked on UI fixes, improvements, and responsive design across screen sizes and devices
